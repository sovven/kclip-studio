## 1. 背景
韩语学习类小红书账号（对标「外研社韩语」，1.6 万粉、23.6 万赞）的主力内容是：**韩综/韩剧/街采短片 + 中韩双语字幕 + 重点表达**。现在单条视频的人工流程是：找片 → 下载 → 听写 → 翻译 → 排版 → 封面 → 文案，耗时 2–3 小时，其中"找片"和"听写"最费时间，选题也全靠感觉。

已经有 `xhs-bilingual-clip` skill 打通了"给链接 → 出成片"。缺的是**选题入口**和**批量管理**。

## 2. 目标与非目标
**目标**
- G1 选题：打开就能看到最近值得做的韩国短视频，并附带 AI 写的推荐理由。没想法的时候 3 分钟内选定选题。
- G2 生产：一键把选题交给 Agent 制作，产出成片、3:4 封面、文案和剪映分层素材；排队处理，不需要盯着。
- G3 交付：在作品库里预览、复制文案、拿到文件路径，发布前人工过一遍。

**非目标（v1 不做）**
- 自动发布到小红书：没有开放接口，而且发布属于账号对外发声，必须由人决定。
- Instagram 抓取：需要用户的登录 cookie，留到 v1.1。
- 多人协作、云端部署。

## 3. 用户与场景
- **运营编辑（主用户）**：每天要发 1–3 条，希望"挑片快、成片稳、文案能直接用"。
- 场景 A：没有选题 → 打开「发现」→ 看「今日推荐」→ 点「一键制作」。
- 场景 B：有方向（比如"这周做获奖感言"）→ 筛选板块或输入关键词 → 把几条加入清单 → 拖动排好顺序 → 批量制作。
- 场景 C：制作完成 → 在「作品库」看成片 → 复制文案 → 打开文件夹拿去剪映微调后发布。

## 4. 信息架构
```
侧边栏
├─ 发现 Discover     今日推荐（AI） + 素材广场（筛选、搜索）
├─ 制作 Studio       待制作清单（可拖动排序） + 进行中任务（流水线进度）
├─ 作品库 Library    已完成作品：封面、成片、文案、剪映素材
└─ 底部：主题切换（浅色 / 深色 / 跟随系统）、Agent 状态
```

## 5. 功能需求
| 编号 | 功能 | 优先级 | 说明 / 验收标准 |
|---|---|---|---|
| F1 | 板块筛选 | P0 | 胶囊多选：综艺搞笑 / 梗 / K-POP / 舞蹈 / 感动·获奖感言 / 韩剧名场面 / 新闻 / 流行 / **外研社同款来源**。选择后自动抓取，结果缓存 30 分钟 |
| F2 | 关键词搜索 | P0 | 输入韩文或中文关键词，在 YouTube Shorts 里搜索 |
| F3 | 今日推荐（AI） | P0 | Claude 从候选里挑 8 条，每条包含：中文小标题、一句话内容、共鸣点、标签、建议封面、评分（1–10）。耗时不超过 90 秒，期间显示骨架屏 |
| F4 | 视频详情抽屉 | P0 | 点卡片从右侧滑出：内嵌播放器、元信息、AI 解读、封面样式选择（带缩略示意）、备注、主按钮「一键制作」、次按钮「加入清单」 |
| F5 | 待制作清单 | P1 | 拖动排序，单条可设置封面和备注，可以批量开始 |
| F6 | 制作流水线 | P0 | 一次只做一条（渲染很吃机器）。按 下载 → 听写 → 字幕 → 渲染 → 封面 → 文案 显示进度和当前动作，失败时给出原因 |
| F7 | 作品库 | P0 | 显示封面、标题、时长；可以播放成片、复制文案、复制文件夹路径；提示"有 N 句听不清已删，发前请检查" |
| F8 | 主题 | P0 | 默认浅色（苹果风格），可以切换深色或跟随系统，选择会被记住 |
| F9 | 时长 / 排序筛选 | P1 | 时长：≤60 秒 / ≤3 分钟；排序：热度 / 最新 |
| F10 | Agent 状态 | P1 | 显示 Claude CLI 是否已登录；没登录时给出引导，不允许点制作 |

## 6. 「外研社同款来源」
根据对其笔记的观察，常见素材来源：韩综官方 Shorts（MBC 엠빅뉴스、tvN《地球娱乐室》、《Yoo Quiz》）、搞笑短剧（숏박스、너덜트、피식대학）、颁奖礼（百想艺术大赏获奖感言）、街头采访、明星访谈切片。v1 用"频道名 + shorts"的组合搜索来覆盖。

## 7. 设计原则
- **苹果风格**：系统字体（SF Pro / PingFang），浅色背景 #F5F5F7，白色卡片，圆角 16–20px，柔和阴影，强调色 #0071E3；深色背景 #000 / #1C1C1E。
- **参考**：81-web.com 的胶囊筛选、分段控件和大图卡片；B 端后台的侧边栏 + 卡片式仪表盘。
- 一屏只有一个主操作（蓝色实心按钮）；次要操作用灰色或描边按钮。
- 不用霓虹、玻璃拟态、大面积渐变。

## 8. 异常与边界
| 情况 | 处理 |
|---|---|
| Claude CLI 未登录 | 顶部黄色提示条，写清"在终端运行 `claude` 然后 `/login`"；禁用制作按钮 |
| 抓取失败或 yt-dlp 过期 | Toast 报错，并提示运行 `yt-dlp -U` |
| 制作失败 | 任务卡显示失败原因，可以重试 |
| 重复提交 | 同一个视频已在队列中或已完成时，不再入队，并提示用户 |

## 9. 指标
- 选题耗时：从打开页面到点下制作，不超过 3 分钟
- 制作成功率 ≥ 90%
- 发布前人工修改字幕的条数（越少越好）

## 10. 风险
- **版权**：素材属于电视台，有被投诉的风险。文案里必须写出处，发不发由用户决定。
- **成本**：每次 AI 推荐和制作都消耗 Claude 用量。推荐结果做缓存，制作按条计。
- **抓取稳定性**：YouTube 改版会导致 yt-dlp 失效，需要定期升级。

## 11. 里程碑
- M1（今天）：PRD、苹果风格界面、发现 / 制作 / 作品库、主题切换
- M2：Instagram 接入、定时每日推荐、记住用户的选片偏好
